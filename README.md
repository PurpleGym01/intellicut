# Intellicut

Инструкция по использованию:
1. Запустите проект в IDE, поддерживающей Python3
2. Установите необходимые библиотеки, указанные в requirements.txt
3. Запустите точку входа - desktop_app.py
4. После завершения трансляции, запись будет сохранена в папку output

Приложение протестировано на MacOS
